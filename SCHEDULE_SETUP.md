# Налаштування розкладу Квітневого ліцею

## Джерела

Уроки: «новий розклад 2027.docx», І семестр 2026–2027. Дзвінки: «Дзвінки.jpg». Перевірено 12.09.2026.

Документ містить лише 5–11 класи. Індивідуального розкладу й розкладу 1–4 класів у ньому немає. Усі п’ять днів містять сім позицій; порожні клітинки залишено порожніми.

У `schedule-config.js` містяться назва школи, класи, порядок днів, усі рядки уроків, відповідність предметів іконкам та дзвінки. Назви предметів розгорнуто зі скорочень. «Математика» й узагальнене «Історія» збережені без поділу на окремі курси. Номери наприкінці клітинок у Word є кодами вчителів; у таблиці учнів показано назви предметів і підгрупи.

## Записи, які потребують уточнення джерела

- 6 клас, середа, 6-й урок: «Англ м(1п)/Техн (1п)7/14». Обидва предмети позначено як 1 підгрупа. Збережено саме так; на сайті є пояснення.
- 10 клас, вівторок, 1-й урок: у парі «Зах.У(1п)/Інф(2п)10/18» порядок кодів учителів відрізняється від інших таких записів.
- 11 клас, четвер, 3-й урок: «Захист(2п)/Інф(1п)10/5» має інший порядок кодів, ніж у понеділок. Сайт не встановлює відповідність цих кодів окремим предметам.

«1п», «2п» означають підгрупи відповідно до розгорнутого написання в документі. Чергування тижнів джерело не визначає.

Усі часові обчислення використовують `Europe/Kyiv`. Якщо онлайн-звірка недоступна, годинник використовує час пристрою. Звукові події уроків відтворюються в будні; календар канікул окремо не заданий. Хвилина мовчання — щодня о 09:00–09:01.

Браузер активує звук після взаємодії зі сторінкою. Для автоматичного відтворення сторінка має бути відкритою, а пристрій — активним. Сусідні вкладки Квітневого узгоджують звукові події через власні ключі `kvitneve.*`; ключі Почуйок не використовуються.

## Адреси та публікація

- `index.html` — загальний розклад.
- `class.html?class=10%20клас` — тиждень 10 класу; аналогічно для всіх класів 5–11.
- `Розклад дзвінків.html` — дзвінки.

GitHub Pages публікує корінь гілки `main` цього окремого репозиторію. Перед оновленням виконати `npm test` та `npm run build`, перевірити змінені дані і відповідні екрани. Усі ресурси сайту мають відносні адреси, придатні для підкаталогу GitHub Pages.

Джерельний DOCX, фото та тимчасові матеріали не включені в репозиторій.

## Відображення таблиць

Таблиці мають компактні рядки, цілі слова в назвах, чергування фону рядків і закріплену колонку номера та часу. Якщо таблиця ширша за екран, з’являються кнопки гортання між колонками. На великих екранах панель класів і пошук займають один рядок.

Однакові назви предмета в межах однієї клітинки відображаються один раз; різні позначення підгруп зберігаються. Це правило діє лише всередині одного уроку. Друк використовує окремий макет A4.

## Зображення тижня кожного класу

`print.html?class=5` … `print.html?class=11` — сторінки перегляду, друку й завантаження готових зображень. На екрані використовується легке WebP-прев’ю; друк і завантаження використовують повнорозмірний PNG 3508 × 2480, 300 dpi. Фон уже включено в PNG, тому він друкується незалежно від налаштування браузера «Фонова графіка».

Кнопка «Друк тижня» на сторінці конкретного класу друкує відповідний PNG. Друк загального дня та дзвінків зберігає табличний формат. Назви днів над загальними таблицями розташовані по центру.

Маніфест `assets/print/manifest.json` зберігає всі 245 вихідних позицій, розміри та контрольні суми PNG, прев’ю, фону й значків. Збірка зупиняється, якщо друковані зображення застаріли відносно конфігурації розкладу. Після правок потрібно запустити `npm run generate:posters` і `npm run build`.
