# Квітневе · Розклад 2026–2027

Розклад уроків **5–11 класів Квітневого ліцею**, І семестр 2026–2027 навчального року.

**Сайт:** https://serhii0304.github.io/Rozklad-Kvitneve/

Перегляд дня, всього тижня або тижня окремого класу; виділення предметів; друк та збереження PDF. Київський час, поточний і наступний урок, таймер до дзвінка, світла і темна теми, адаптація до телефона, автоматичні шкільні дзвінки та хвилина мовчання о 09:00.

Усі 245 позицій перенесено з документа «новий розклад 2027.docx»: 226 заповнених і 19 порожніх. Дзвінки перенесено з «Дзвінки.jpg»: 08:50–15:25. Підгрупи та поєднані предмети збережено; кожен предмет можна виділяти окремо.

Функціональність адаптована з [розкладу Почуйок](https://github.com/Serhii0304/Rozklad-Pochuyki). Новий проєкт має власний репозиторій і окремі ключі теми та звуку. Інші розклади не змінювалися.

## Локальний запуск

Потрібен Node.js; сторонні пакети встановлювати не потрібно.

```sh
npm run dev
npm test
npm run build
```

Локальна адреса: http://localhost:4173/. Готові файли збираються в `build/`.

Дані й обмеження джерела описані в [SCHEDULE_SETUP.md](SCHEDULE_SETUP.md).
