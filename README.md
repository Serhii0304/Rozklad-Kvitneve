# Квітневе · Розклад 2026–2027

Розклад уроків **5–11 класів Квітневого ліцею**, І семестр 2026–2027 навчального року.

**Сайт:** https://serhii0304.github.io/Rozklad-Kvitneve/

Перегляд дня, всього тижня або тижня окремого класу; виділення предметів; друк та збереження PDF. Київський час, поточний і наступний урок, таймер до дзвінка, світла і темна теми, адаптація до телефона, автоматичні шкільні дзвінки та хвилина мовчання о 09:00.

Усі 245 позицій перенесено з документа «новий розклад 2027.docx»: 226 заповнених і 19 порожніх. Дзвінки перенесено з «Дзвінки.jpg»: 08:50–15:25. Підгрупи та поєднані предмети збережено; кожен предмет можна виділяти окремо.

Функціональність адаптована з [розкладу Почуйок](https://github.com/Serhii0304/Rozklad-Pochuyki). Новий проєкт має власний репозиторій і окремі ключі теми та звуку. Інші розклади не змінювалися.

## Локальний запуск

Потрібен Node.js; сторонні пакети встановлювати не потрібно.

```sh
npm run dev
npm test
npm run build
```

Локальна адреса: http://localhost:4173/. Готові файли збираються в `build/`.

Дані й обмеження джерела описані в [SCHEDULE_SETUP.md](SCHEDULE_SETUP.md).

## Повністю згенеровані зображення для друку

[Сторінки друку 5–11 класів](https://serhii0304.github.io/Rozklad-Kvitneve/print.html) містять сім цілісних зображень. Вбудований ImageGen створив усе зображення разом: текст, таблицю, ілюстрації та фон. Назва ліцею, «Розклад уроків», клас і навчальний рік розміщені по центру над таблицею.

Повні PNG у `assets/print/class-5-week.png` … `class-11-week.png` є незміненими оригіналами ImageGen. Текстові накладання, програмне малювання таблиці й штучне збільшення оригіналів не застосовуються. Сторінка показує фактичну нативну роздільність завантаженого PNG. Легкі WebP-прев’ю створено лише для швидкого перегляду.

Точні запити та записи візуальної перевірки збережені в `assets/print-generation/`. Кожне зображення перевірене по всіх 35 клітинках, заголовках і семи дзвінках. Контрольні суми гарантують, що опубліковано саме прийнятий після перевірки файл; вони не замінюють перевірку тексту на самому зображенні.

Після зміни розкладу потрібна нова повна генерація через ImageGen та повторна візуальна перевірка. Імпорт приймає лише сім перевірених оригіналів `class-N.png` з файлами `class-N-review.json`:

```sh
npm install
npm run import:posters -- --source-dir <папка-з-перевіреними-PNG>
npm run validate:posters
npm run build
```

`sharp` використовується тільки для читання розмірів PNG та створення WebP-прев’ю. Статичний сайт і перевірка готових файлів працюють без сторонніх пакетів.

## Загальний тиждень і PDF без службових написів

[Загальний тиждень для друку](https://serhii0304.github.io/Rozklad-Kvitneve/week-print.html) — п’ять сторінок однакового затвердженого стилю, по одному дню для всіх 5–11 класів. Кнопка «Друк тижня» на головній завантажує `assets/print-week/week-all-classes.pdf`; друк дня — PDF відповідного дня.

Для кожного класу також створено односторінковий PDF: `assets/print/class-5-week.pdf` … `class-11-week.pdf`. Кнопки друку завантажують готовий PDF. Його потрібно відкрити й надрукувати у PDF-переглядачі. Це працює також у вбудованих браузерах без підтримки нових PDF-вкладок; основна сторінка зі звуками залишається відкритою. Дата, адреса сайту та колонтитули HTML-сторінки не потрапляють на аркуш.

Усі 13 PDF містять лише прийняте зображення на A4 297 × 210 мм, пропорційно вміщене по центру з полями щонайменше 5 мм для звичайного принтера. Рамки та таблиці збережені повністю; текстових колонтитулів немає. Якщо принтер потребує більших полів, оберіть «Вмістити в область друку» у його діалозі.

Усі 12 PNG для завантаження та їхні вебперегляди також мають ці поля. Вони відрендеровані з перевірених PDF у `assets/print-ready/`; первинні зображення ImageGen збережені окремо без змін. Рендер 300 dpi не додає деталей понад оригінал. Після створення PDF запустіть `python scripts/build-print-images.py` та `node scripts/validate-print-images.mjs` перед збіркою сайту.

Повторне створення PDF після оновлення прийнятих PNG:

```sh
python scripts/build-print-pdfs.py
python scripts/build-print-pdfs.py --check
npm run validate:pdfs
npm run build
```

Потрібні Python, ReportLab, Pillow і pypdf. Маніфест `assets/print-pdfs.json` пов’язує PDF з точними PNG та містить координати зображень та перевірки безпечних полів, пропорцій, відсутності тексту й анотацій. Усі 17 сторінок відрендеровані Poppler і перевірені.

## Дзвінки та зображення для друку

Сторінка дзвінків має компактні кольорові ряди по центру, точні інтервали всіх шести перерв і відлік поточного уроку або перерви. Нумеруються лише уроки; проміжки навколо рядів відкривають шкільний фон.

[bells-print.html](https://serhii0304.github.io/Rozklad-Kvitneve/bells-print.html) містить цілісне згенероване зображення із синьо-жовтим орнаментом. PDF і PNG — A4 у книжковій орієнтації, з полями щонайменше 5 мм. Кнопка друку дзвінків завантажує цей PDF. Джерело, запит і перевірка — у `assets/print-bells/`; текст і таблиця є частиною зображення ImageGen.

Після прийняття нового зображення: `python scripts/build-bells-print.py`, `python scripts/build-bells-print.py --check`, `node scripts/validate-bells-print.mjs`, `npm run build`. Зміна дзвінків у конфігурації потребує нового зображення й перевірки його тексту.
