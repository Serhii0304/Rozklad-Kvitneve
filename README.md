# Квітневе · Розклад 2026–2027

Розклад уроків **5–11 класів Квітневого ліцею**, І семестр 2026–2027 навчального року.

**Сайт:** https://serhii0304.github.io/Rozklad-Kvitneve/

Перегляд дня, всього тижня або тижня окремого класу; виділення предметів; друк та збереження PDF. Київський час, поточний і наступний урок, таймер до дзвінка, світла і темна теми, адаптація до телефона, автоматичні шкільні дзвінки та хвилина мовчання о 09:00.

Усі 245 позицій перенесено з документа «новий розклад 2027.docx»: 226 заповнених і 19 порожніх. Дзвінки перенесено з «Дзвінки.jpg»: 08:50–15:25. Підгрупи та поєднані предмети збережено; кожен предмет можна виділяти окремо.

Функціональність адаптована з [розкладу Почуйок](https://github.com/Serhii0304/Rozklad-Pochuyki). Новий проєкт має власний репозиторій і окремі ключі теми та звуку. Інші розклади не змінювалися.

## Локальний запуск

Потрібен Node.js; сторонні пакети встановлювати не потрібно.

```sh
npm run dev
npm test
npm run build
```

Локальна адреса: http://localhost:4173/. Готові файли збираються в `build/`.

Дані й обмеження джерела описані в [SCHEDULE_SETUP.md](SCHEDULE_SETUP.md).

## Окремі зображення для друку

[Сторінки друку 5–11 класів](https://serhii0304.github.io/Rozklad-Kvitneve/print.html) містять сім різних тижневих зображень. Кожен PNG має розмір 3508 × 2480 px, 300 dpi, формат A4 альбомний, власний художній фон і точний розклад відповідного класу. На сторінці можна вибрати клас, роздрукувати або зберегти PNG. Кнопка друку тижня на сторінці класу також використовує його зображення.

Файли: `assets/print/class-5-week.png` … `class-11-week.png`. Полегшені прев’ю мають суфікс `-preview.webp`. Набір із 24 оригінальних SVG-значків для друку: `assets/print-subjects/`; різні предмети не використовують однакового малюнка.

Фони створено вбудованим ImageGen; точні запити збережені в [PROMPTS.md](assets/print-backgrounds/PROMPTS.md). Текст, дзвінки й клітинки накладені програмно з `schedule-config.js`, тому художня генерація не змінює розклад.

Після зміни даних або друкованих значків зображення потрібно перегенерувати:

```sh
npm install
npm run generate:posters
npm run validate:posters
npm run build
```

Для відтворення цього оформлення потрібен шрифт Segoe UI. Звичайний статичний сайт і перевірка готових PNG працюють без встановлення пакетів; `sharp` потрібен лише для повторного створення зображень.
